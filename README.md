# 우리 반 사례 연결

3학년 사회 공개수업(옛날과 오늘날의 생활 모습, 조직하기 단계) 활동 1·2에서 쓰는 실시간 사례 연결 보드입니다.

- 1~4모둠이 교통수단·통신수단 변화 사례를 한 칸씩 입력합니다(옛날에는 / 오늘날에는 / 왜 바뀌었을까?).
- 2단계에서 사례를 '사람들의 필요'와 '기술 발달'로 끌어 모읍니다.
- 개념적 질문의 답을 쓰고, 활동 2에서 우리 고장(문경) 사례를 추가해 확인합니다.
- 선생님 도구(질문 고치기, 모은 사례 되돌리기, 모든 내용 지우기)는 비밀번호로 엽니다.

## 설정
1. `firebase-config.js`에 Firebase 웹 앱 설정값을 넣습니다.
2. Firebase 콘솔의 Firestore 규칙에 `firestore.rules` 내용을 붙여 넣고 게시합니다.
3. GitHub Pages(Settings > Pages > main 브랜치 / root)로 배포합니다.
